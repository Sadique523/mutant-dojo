# Skeletal Leo binding prototype

Mesh/materials: existing project Leo prototype, generated by art/build_scene.py.
Skeleton and animations: Quaternius Universal Animation Library Standard, CC0 1.0.
Full license and source provenance: ../motions/quaternius/LICENSE and PROVENANCE.md.

The reference skeleton was scaled uniformly and existing mesh pieces fitted to its rest pose in Blender. Torso weights blend across spine bones; disconnected limb and weapon pieces remain rigidly weighted. Sixteen selected library clips retain their names. This is a pipeline prototype, not a finished sculpt, smooth limb skinning, or polished combat animation.
