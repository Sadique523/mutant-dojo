# Skeletal Raphael binding prototype

Mesh/materials/sai: existing project Raphael prototype, generated by art/build_scene.py.
Skeleton and 16 library animations: Quaternius Universal Animation Library Standard, CC0 1.0.
License and provenance: ../motions/quaternius/LICENSE and PROVENANCE.md.

Reference skeleton scaled uniformly; existing mesh pieces fitted to its rest pose in Blender. Torso weights blend across spine bones; disconnected limbs and sai are rigidly weighted. The game generates the shared taller idle and raised block poses. Heavy attacks use Punch_Cross rather than Leo's sword cut. This remains a binding prototype with unfinished joint topology and skinning.
